QLCM-notation is a notation for quantum circuits looks like this:

[
	[block 1],
	[block 2],
	[block 3],
	...
]

A block is an element of the quantum circuit like for example a qubit or a gate and includes a unique id, a step declaration that defines what kind of circuit element this block is and a list of inputs and outputs which are the preceding or following blocks in the circuit. If there are no inputs or outputs the corresponding list stays empty.

These are the representations for the possible blocks (But the input and output lists are filled with the maximum possible length of the list instead of an actual list):

1. A Qubit is represented like this:
[id: "Q_n", step: "Qubit", inputs: [0], outputs: [1]]

2. A Hadamard gate looks like this:
[id: "H_n", step: "Hadamard", inputs: [1], outputs: [1]]

3. A Pauli Z gate looks like this and changes the Phase of the qubit if it 1 otherwise it does not change the phase:
[id: "Z_n", step: "Z", inputs: [1], outputs: [1]]

4. Controlled-X gate (CNOT gate) (The first input in the list is the control input, the second is the target input):

[id: "CNOT_n", step: "CNOT", inputs: [2], outputs: [2]]

5. Classical Bit:
[id: "B_n", step: "Bit", inputs: [0], outputs: [1]]

6. Basis Encoder (Encodes a classical Bit into a quantum register with Basis Encoding):
[id: "BE_n", step: "BitEncoder", inputs: [1], outputs: [1]]

7. Addition Block that takes two quantum registers and adds them together in one output:
[id: "A_n", step: "Addition", inputs: [2], outputs: [1]]

8. Subtraction Block that takes two quantum registers and subtracts the second from the first:
[id: "Sub_n", step: "Subtraction", inputs: [2], outputs: [1]]

9. Division Block that takes two quantum registers and divides the first input by the second input:
[id: "Div_n", step: "Division", inputs: [2], outputs: [1]]

10. Multiplication Block that takes two quantum registers and multiplies them together in one output:
[id: "Mul_n", step: "Multiplication", inputs: [2], outputs: [1]]

11. Measurement Block, that measures a quantum state: (compact)
[id: "Msr_n", step: "Measurement", inputs: [1], outputs: [1]]
